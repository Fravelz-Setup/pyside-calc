# pyside-calc


Calculadora flotante de escritorio. Se abre como comando local, evalúa una expresión y puede guardar notas al lado.

| | |
| --- | --- |
| Autor | [Fravelz](https://github.com/FraVelz) |
| Licencia | No hay archivo de licencia en el repositorio. |

## Tecnologías

- Python 3.11+
- PySide6

## Estructura base

Esqueleto del repositorio. El contenido interno cambia; estas piezas se mantienen.

```text
src/pyside_calc/    aplicación
scripts/            lanzador
```

## Puesta en marcha

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
./scripts/pyside-calc
```
